# Self-hosted Spline assets

Generated by `npm run vendor:spline`. Do not edit by hand; edit the script.

- `viewer/` is the `<spline-viewer>` web component from `@splinetool/viewer@1.9.82`
  (`build/*.js`), plus the wasm modules it loads on demand. Its hard-coded
  unpkg URLs are rewritten to point here, so nothing is fetched from Spline's
  servers at run time.
- `nexbot.splinecode` is the hero scene, downloaded from
  `https://prod.spline.design/85ncNDchXqwFW2zI/scene.splinecode`.

Robot model: NEXBOT by ahmedkhaledemara0909 (Spline community), CC BY 4.0.
The credit is shown in the site footer.

To update the viewer: `node scripts/vendor-spline.mjs <version>` and update the version above.
